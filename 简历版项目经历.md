# 简历版项目经历（Resume Version）

## 动物智能检测系统 - AnimalVision
**基于YOLOv11与DeepSeek大模型的智能动物识别与问答系统**

### 项目描述
开发了一个集动物识别、智能问答、预警监控于一体的Web应用系统，支持80种动物的实时检测与知识科普。系统采用前后端分离架构，后端使用FastAPI + YOLOv11实现高性能目标检测，前端采用原生JavaScript实现流畅交互，集成DeepSeek大模型提供智能问答服务。

### 技术栈
- **后端**：Python、FastAPI、PyTorch、YOLOv11、OpenCV
- **前端**：HTML5、CSS3、JavaScript(ES6+)、WebSocket
- **AI模型**：YOLOv11n（目标检测）、DeepSeek-R1（问答系统）
- **工具**：Ollama API、NumPy、Pillow

### 核心职责与成果

#### 【Situation】
传统动物识别效率低下，缺乏自动化和智能问答功能，无法满足科普教育和生态研究的实际需求。

#### 【Task】
- 实现高精度动物检测（支持图片、视频批量处理）
- 开发实时监控预警系统（可配置80种动物预警规则）
- 集成AI智能问答（提供专业动物知识解答）
- 构建数据统计分析平台（历史记录管理与可视化）

#### 【Action】
1. **模型训练与部署**
   - 自主训练YOLOv11n轻量级模型（5.3MB），检测准确率达工程应用水平
   - 实现GPU加速推理，单张图片处理时间<0.5秒
   - 使用`@asynccontextmanager`优化模型生命周期管理

2. **后端架构设计**（约770行Python代码）
   - 基于FastAPI构建RESTful API，支持异步并发处理
   - 实现WebSocket实时通信，降低检测延迟
   - 开发自动清理机制（图片保留1000个，视频保留100个）
   - 设计模块化架构：检测模块、预警系统、数据统计、历史管理

3. **核心功能实现**
   - **批量检测**：支持图片/视频混合上传，自动标注并打包下载
   - **实时预警**：动态读写预警配置，检测到目标动物自动触发警报
   - **数据统计**：按日统计识别数量和预警信息，持久化存储
   - **AI对话**：集成Ollama API调用DeepSeek模型，支持文本和语音交互

4. **前端开发**（约600行HTML/CSS/JS）
   - 实现拖拽上传、实时预览、结果可视化等交互功能
   - 使用Canvas绘制检测框，标注动物种类和置信度
   - 开发数据统计面板，展示历史记录和趋势分析
   - 设计响应式布局，支持桌面端和移动端访问

5. **性能优化**
   - GPU显存管理：及时释放资源，防止内存泄漏
   - 异步处理：利用FastAPI异步特性，提升系统吞吐量
   - 批量优化：并行处理多个文件，减少等待时间

#### 【Result】
- ✅ **系统性能**：单张图片检测<0.5秒，支持多用户并发访问，系统稳定运行7x24小时
- ✅ **功能完整度**：实现100%需求覆盖，支持多格式（6种图片格式+3种视频格式）
- ✅ **代码质量**：约1500行高质量代码，模块化设计，易维护易扩展
- ✅ **技术创新**：双模型集成（视觉+语言），多模态交互（文本+语音+图像）
- ✅ **应用价值**：适用于科普教育、生态研究、智慧园区等多个场景

### 技术亮点
1. **深度学习工程化**：完成从模型训练、优化到部署的全流程实践
2. **异步高并发**：FastAPI + WebSocket实现高性能实时通信

## Animal Intelligence Detection System - AnimalVision
**Intelligent Animal Recognition and Q&A System Based on YOLOv11 and DeepSeek LLM**

### Project Description
Developed a comprehensive web application integrating animal recognition, intelligent Q&A, and warning monitoring, supporting real-time detection of 80 animal species with educational features. The system adopts a frontend-backend separation architecture, utilizing FastAPI + YOLOv11 for high-performance object detection on the backend, and native JavaScript for smooth interactions on the frontend, integrated with DeepSeek LLM for intelligent Q&A services.

### Tech Stack
- **Backend**: Python, FastAPI, PyTorch, YOLOv11, OpenCV
- **Frontend**: HTML5, CSS3, JavaScript (ES6+), WebSocket
- **AI Models**: YOLOv11n (Object Detection), DeepSeek-R1 (Q&A System)
- **Tools**: Ollama API, NumPy, Pillow

### Key Responsibilities & Achievements

#### 【Situation】
Traditional animal identification methods were inefficient, lacking automation and intelligent Q&A capabilities, unable to meet the practical needs of science education and ecological research.

#### 【Task】
- Implement high-precision animal detection (support batch processing of images and videos)
- Develop real-time monitoring warning system (configurable rules for 80 animal species)
- Integrate AI intelligent Q&A (provide professional animal knowledge answers)
- Build data statistics and analysis platform (historical record management and visualization)

#### 【Action】
1. **Model Training & Deployment**
   - Self-trained YOLOv11n lightweight model (5.3MB) achieving engineering application-level accuracy
   - Implemented GPU-accelerated inference with <0.5s processing time per image
   - Optimized model lifecycle management using `@asynccontextmanager`

2. **Backend Architecture Design** (~770 lines of Python code)
   - Built RESTful API based on FastAPI with asynchronous concurrent processing
   - Implemented WebSocket real-time communication to reduce detection latency
   - Developed auto-cleanup mechanism (keep 1000 images, 100 videos)
   - Designed modular architecture: detection, warning, statistics, history modules

3. **Core Feature Implementation**
   - **Batch Detection**: Support mixed upload of images/videos, auto-annotation and packaged download
   - **Real-time Warning**: Dynamic warning configuration with auto-alert on target animal detection
   - **Data Statistics**: Daily statistics of detection count and warning info with persistent storage
   - **AI Dialogue**: Integrated Ollama API calling DeepSeek model with text and voice interaction

4. **Frontend Development** (~600 lines HTML/CSS/JS)
   - Implemented drag-and-drop upload, real-time preview, result visualization
   - Used Canvas to draw detection boxes with animal class and confidence labels
   - Developed data statistics dashboard displaying history and trend analysis
   - Designed responsive layout supporting desktop and mobile access

5. **Performance Optimization**
   - GPU memory management: Timely resource release to prevent memory leaks
   - Async processing: Leveraged FastAPI async features for improved throughput
   - Batch optimization: Parallel processing of multiple files to reduce wait time

#### 【Result】
- ✅ **System Performance**: <0.5s per image detection, support multi-user concurrent access, 24/7 stable operation
- ✅ **Feature Completeness**: 100% requirement coverage, support multi-format (6 image + 3 video formats)
- ✅ **Code Quality**: ~1500 lines of high-quality code, modular design, easy to maintain and extend
- ✅ **Technical Innovation**: Dual-model integration (vision + language), multi-modal interaction (text + voice + image)
- ✅ **Application Value**: Applicable to science education, ecological research, smart parks, and more

### Technical Highlights
1. **Deep Learning Engineering**: Complete pipeline from model training, optimization to deployment
2. **Async High Concurrency**: FastAPI + WebSocket for high-performance real-time communication
3. **Full-stack Development**: Independently completed frontend and backend design and implementation
4. **AI System Integration**: Deep integration of YOLOv11 and DeepSeek LLM
5. **Engineering Mindset**: Focus on code quality, performance optimization, resource management

### Personal Growth
- Mastered object detection model (YOLO series) training, tuning, and deployment
- Enhanced full-stack development skills, familiar with FastAPI, WebSocket, async programming
- Accumulated LLM integration experience, understanding Ollama API and model fine-tuning
- Strengthened engineering mindset, focusing on system architecture, module design, exception handling
